Change:
- Capture grass map readiness, texture and exact U/V vectors once per explicitly
  prepared, synchronous camera pass. Direct callers capture each TryRender call.
- Each privately owned indirect draw MPB remembers its applied binding. Skip the
  four setters when texture identity, readiness and exact vectors still match.
- Texture pixels may update in place: no rebind needed, shader still sees them.
- Texture replacement, not-ready fallback, world/extent changes, new cameras and
  new/recreated draw blocks bind updated values. No global material properties.
- Source shaders, compute shader, placement, density, LOD, distances, shadows,
  command count/order and all submitted draw parameters are unchanged.
- CPU fallback Bind remains unconditional. Cached Shader.PropertyToID values are
  shared by both binding paths. No readbacks or cross-frame camera/culling cache.
- Cache is only valid for its owned block. An external Clear/write requires Reset;
  production GPU blocks are private to Draw and never externally exposed.
