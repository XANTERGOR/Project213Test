Junction foundation terrain LOD (2026-10-10)

Road Junction now has the same opt-out and edge-error controls as Road:
  simplifyTerrainUnderAsphalt = true
  terrainLODEdgeError = 0.03 metres (0..1)

The three terrain LOD paths (deferred/local, whole-chunk legacy and spatial)
retain the old full junction bounds lock ONLY when no usable generated surface
can be captured, or the option is disabled. Otherwise the shared road clearance
protection checks actual emitted terrain triangles against ALL generated junction
LODs, with the shared reference-height constraint for outer edges and holes.
This does not reduce the LOD0/collider plan, change authored meshes/materials,
or guarantee that terrain already intersecting sunk asphalt can be simplified.

Capture reads the owned generated root's LTRoadLOD array, not source meshes or
the current MeshFilter. Existing generated output is usable without migration.
While source changes await baking, currently published geometry remains the
clearance reference. Replacing output, mesh dirty/dependency revisions, parent
transforms and edge-error edits change the live stamp key. Missing, foreign,
inactive, unreadable or unsupported output keeps a conservative fallback.
Only junction stamp version changes, not the global world configuration: old
and new affected bounds are invalidated through the existing Detect/Mark path.
No scene-stored transient instance-ID hash or new rebuild-on-reload is added.
Warm polls reuse immutable CPU surfaces and metadata keys; profiling marker:
  LT.Editor.Capture.JunctionFoundation
